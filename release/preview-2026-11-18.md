# Waarp preview — 18 November 2026

> **PREVIEW / TEST BUILDS — NOT STABLE.** This release is tied to one Git commit and must not be described as a validated production VPN for every device or network.

## What's included

**Windows — 0.4.1-rc.2 (x64 portable):** per-app and per-site routing, personal VPN/proxy profiles, guarded live rule updates, explicit consent before structural TUN restarts, source-based public-node registry and on-demand diagnostics. This is not a multipath product, and network outcomes are provider-dependent.

**Android — 0.5.0-rc.4 (API 29+, per-ABI debug APKs):** native Kotlin/Compose app, actual Android VpnService, selected-app routing, supported protocol imports, guarded live updates, explicit public-pool refresh and diagnostics. The APKs in this preview are **debug-signed development builds**, package ID `local.waarp.android.debug`; they do not update a production-signed app.

## Files

| Pattern | Description |
| --- | --- |
| `Waarp-0.4.1-rc.2-portable.exe` | Windows 10/11 x64 portable, unsigned |
| `waarp-android-0.5.0-rc.4-arm64-v8a-debug.apk` | Android debug, most current ARM64 phones |
| `waarp-android-0.5.0-rc.4-armeabi-v7a-debug.apk` | Android debug, 32-bit ARM |
| `waarp-android-0.5.0-rc.4-x86_64-debug.apk` | Android debug, x86_64 |
| `SHA256SUMS-windows.txt` / `SHA256SUMS-android-debug.txt` | SHA-256 manifests generated from published files |

**Never install an unsigned release APK.** The production signing key is retained separately and is not supplied to CI.

## Known boundaries

- Preview checks run on controlled environments. They do not substitute for the full [stable Windows matrix](../docs/STABLE-AUDIT-2026-11-16.md) or [Android optimized release/2-hour soak acceptance](../docs/ANDROID.md#optimized-release-approval).
- Routing through a public node is a trust decision; operators are independent of Waarp and endpoints can disappear.
- No independent always-on leak-proof firewall kill switch is promised.
- The dependency audit has an unresolved upstream build-tool advisory documented in [the build audit](../docs/BUILD-AUDIT-2026-11-18.md). Functional checks and security status must be evaluated separately.

For features and install instructions see the [project README](../README.md), [Russian README](../README.ru.md) and [release policy](../docs/RELEASES.md).
