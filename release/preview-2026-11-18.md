# Waarp 1.0.0 preview — 22 ноября 2026

Актуальная предварительная сборка для **Windows 10/11 x64** и **Android 10+**. Windows и все три Android APK собираются из одного исходного коммита; точная ссылка на него добавляется ниже при подготовке выпуска.

## Что входит

- Текущее приложение для выбора маршрута приложения или домена: Direct, Auto либо выбранное личное подключение.
- Языковые ресурсы для 19 языков с проверкой ключей, параметров, форматов и форм множественного числа.
- Windows-пакет без отдельной дублирующей runtime-копии `simple-icons`: используемые иконки и лицензия сохранены. Состав и размеры фактической сборки перечислены в `package-inventory.txt`.
- Учёт DEX, ресурсов, assets и native-библиотек Android. APK остаются отдельными полными приложениями для трёх архитектур.

## Файлы для установки

| Файл | Для какой системы |
| --- | --- |
| `Waarp-1.0.0-portable.exe` | Windows 10/11 x64; portable, без цифровой подписи издателя |
| `waarp-android-1.0.0-arm64-v8a-debug.apk` | Android 10+ ARM64; большинство современных телефонов |
| `waarp-android-1.0.0-armeabi-v7a-debug.apk` | Android 10+ на совместимых 32-битных ARM-устройствах |
| `waarp-android-1.0.0-x86_64-debug.apk` | Android 10+ x86_64; совместимые устройства и эмуляторы |

Выбирайте один APK своей архитектуры. Android APK показывают версию `1.0.0-debug`, versionCode `7` и используют package `local.waarp.android.debug`.

## Проверки перед публикацией

Выпуск остаётся черновиком, пока не пройдут все заявленные этапы:

- Windows: typecheck, offline/source/performance/UI checks, реальные TCP/UDP/DNS и проверки сохранения соединения при изменении маршрута.
- Готовый Windows EXE: три запуска, сохранение зашифрованного профиля, штатный выход, замена тем же кандидатом и все девять встроенных брендовых SVG.
- Готовое Windows-приложение: реальный ответ публичного узла до импорта, продолжение проверок при включённом VPN и сохранение выбранного маршрута; затем 50 native TUN lifecycle cycles.
- Android: сборка из закреплённого native source, JVM/lint, проверка подписей и 16 KB alignment, API 35 route/feedback и UI gallery.
- Финальная сверка коммита, версии, набора файлов и SHA-256 опубликованных assets. Отчёт portable lifecycle должен относиться к тому же EXE и ASAR.

Результат публичных сетевых проверок относится к сети GitHub Windows runner и измеренному набору узлов. Он не гарантирует доступность всех сторонних серверов у любого провайдера.

## Обновление существующей установки

**Windows.** Штатно завершите Waarp перед заменой portable EXE. Идентичность приложения и каталог настроек сохранены. Автоматического обновления в приложении нет. Проверка трёх запусков использует замену тем же кандидатом; переход между разными версиями не объявляется отдельной выполненной migration-приёмкой.

**Android.** Это debug preview, отдельный от production-приложения `local.waarp.android`. Установка поверх старой версии возможна только при совпадении package ID и сертификата. Постоянный debug-ключ между CI-сборками не закреплён, поэтому обновление поверх r5 не гарантируется. При конфликте подписи сохраните текущую установку и данные; не удаляйте приложение только ради принудительного обновления. Obtainium может выбрать новый файл по архитектуре, но не отменяет проверку подписи Android.

## Целостность и область выпуска

Для файлов установки приложены `SHA256SUMS-windows.txt` и `SHA256SUMS-android-debug.txt`. Дополнительно опубликованы `package-integrity-windows.json`, `package-inventory.txt`, `portable-lifecycle.json`, `public-catalog-windows.json`, `android-artifacts.json` и соответствующий исходный архив Windows-движка `sing-box-lx-1.14.2-lx.11-src.tar.gz`.

Это **prerelease**, а не production/stable. Полная optimized Android matrix, двухчасовой encrypted soak, физическая install/update-приёмка и подпись сохранённым production-ключом остаются отдельными условиями. Последний полный Android candidate не был принят; публикация preview не меняет этот статус. Windows UAC, переход между разными версиями и физические sleep/network/other-VPN сценарии также не засчитываются за счёт hosted CI.
