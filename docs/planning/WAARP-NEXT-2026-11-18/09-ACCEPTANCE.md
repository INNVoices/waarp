## Что доведено

| Область | Фактическое поведение |
| --- | --- |
| Карта Windows | Локальный Atlas встроен в прежний выбор подключения. Регион устройства, фильтр и выбранная страна обновляются вместе с видимыми данными; общая задержка обновления на 250 ms устранена. Список, поиск, страницы, unknown и явный выбор сохраняются; отказ WebGL оставляет список |
| Android | Карта остаётся в «Туннелях» и существующей форме. Ручной регион хранится как общая UI-настройка, сохраняется между списком, картой и формами и не меняет VPN intent/revision. Кнопки региона допускают перенос; нижняя навигация использует перенос русских слов и проверена при шрифте 150% |
| Контекстная проверка | Карточка передаёт свою цель, назначение и путь в существующую диагностику. Запросы ограничены, отменяемы и имеют проверку актуальности результата. Windows теперь учитывает текущий публичный путь при ON, если он уже загружен в ядро; другие публичные узлы не становятся альтернативами. Отозванные и исчезнувшие из подписки записи исключены |
| Результат и применение | Отвечающий текущий путь сохраняется. Рекомендация требует двух завершённых отказов текущего и двух ответов допустимой альтернативы. Windows применяет выбор к нужной карточке; Android сохраняет результат в черновике до единственного «Сохранить маршрут». Счётчик ответов Windows остаётся целым при длинных названиях |
| Нативное управление | Сохранён один владелец изменений и прежние core pins. Необязательные изменения удерживают активный путь при active/unknown; ручные действия, OFF и подтверждённый отказ сохраняют свой приоритет. Проверенные live-изменения сохраняют основной PID/TUN и соседний поток |
| Доставка | Существующий preview workflow загружает проверенные EXE/APK напрямую в GitHub Releases. Версии и source identity совпадают; квота Actions artifacts не помешала публикации этого preview |

Карта использует локальные MapLibre/Natural Earth, без tile/GeoIP backend и новых location permissions. Страны означают регион из источника, ручная точка — выбранный пользователем регион; линия Windows показывает логическую связь, а не traceroute. Просмотр, фильтрация и смена региона не запускают TUN или применение маршрута. [Руководство](../../CONNECTION-TOOLS.md) · [Данные и лицензии](../../ATLAS-DATA.md).

## История отказов сохранена

На промежуточном `da5130c` общий Windows run `44309773049` превысил прежний 90 s budget после успешных Atlas/quality сценариев; точные cycle metrics этого отказа в доступном журнале отсутствуют. Отдельный preview того же SHA прошёл UI. На `8482dfc` оба Windows UI-прогона прошли с тем же бюджетом; причина предыдущего превышения не установлена и не объявляется исправленной изменением Android. Android `8482dfc` прошёл native 5 и JVM 204, но gallery остановилась на неоднозначном matcher текста France: он находил и поисковое поле, и строку страны. Исправлен выбор именно строки. Реальный кадр 150% также показал одиночную букву в переносе подписи навигации; в `928c9a8` добавлен стандартный перенос русских слов с сохранением размера шрифта. `54a72e0` заменён до загрузки assets в r5. На текущем `928c9a8` общий Windows run 44316534397/job 134844018930 снова превысил тот же 90 s бюджет; последующие route-native, 50 TUN и packaging были пропущены; отдельный selector experiment выполнился и прошёл. Обязательный preview прошёл 100 cycles с прежним порогом. Точная причина расхождения не установлена; отказ общего прогона сохранён отдельно и не относится к artifact quota. Подробности — в [журнале](08-IMPLEMENTATION.md).

Более ранний `2305781` имел timeout lifecycle snapshot после 15/50 и успешный повтор 50/50; его [evidence](evidence/2305781/README.md) и [старые изображения](../../screenshots/atlas-2026-11-18/README.md) сохранены как история. Они не подменяют текущие данные.

## Границы результата

- Контекстное сравнение измеряет **HTTP(S)-доступность**. Назначения «Игры/Голос/Видео/Веб» не доказывают игровую UDP-сессию, потери, jitter или QoE и не перенастраивают транспорт. Системные DNS/TCP/TLS/HTTP шаги могут следовать активным маршрутам ОС; проверки конкретного подключения адресуются native outbound.
- Production selectors сохраняют `interrupt_exist_connections: true`; продуктовый результат — удержание рабочего пути при необязательной смене. Универсальный soft drain, перенос сессии между внешними IP, физический handover и целевые миллисекунды паузы не установлены этой приёмкой.
- Это **preview**: EXE без цифровой подписи, APK с debug-подписью. Полная Android API 29/35/36, optimized-release и двухчасовая soak-матрица по-прежнему зависит от недоступной Actions artifact delivery. Физические устройства, TalkBack/landscape и оставшиеся масштабы шрифта относятся к отдельной stable-приёмке.
- Отдельный полный audit build toolchain остаётся красным по известному `picomatch` advisory; runtime JavaScript audit дал 0. Общие CI uploads также отказали по storage quota; отдельный общий Windows UI gate имеет описанный выше превышение 90-секундного бюджета. Успешный выпуск напрямую в Releases не переименовывает эти отказы в PASS. [Точный аудит](../../BUILD-AUDIT-2026-11-18.md).

Более широкий исходный WN-план — UDP/QoE, дополнительные native capabilities, versioned method/source metadata, product drain и Community Atlas — сохраняется в [task-status.json](task-status.json). Эти отдельные направления не добавлялись в команду завершить текущие компоненты. Путь вклада в существующие presets описан в [CONNECTION-PROFILES.md](../../CONNECTION-PROFILES.md).
