# Support / Поддержка Waarp

**English:** Start with [documentation](docs/README.md), [downloads and release status](docs/RELEASES.md), and [known limitations](docs/RELIABILITY.md). For reproducible non-security bugs, [open an issue](../../issues/new/choose) using a template and include the version, platform, expected/actual behavior and sanitized reproduction steps.

**Русский:** Сначала проверьте [документацию](docs/README.md), [статус сборок и релизов](docs/RELEASES.md), [известные ограничения](docs/RELIABILITY.md). Обычные баги присылайте через [шаблон issue](../../issues/new/choose): версия, ОС/Android API, шаги воспроизведения и фактический результат.

**Security:** Report vulnerabilities privately via [SECURITY.md](SECURITY.md). Never paste real private keys, personal proxy endpoints, subscription URLs, device identifiers or tokens into public issues/screenshots. Waarp does not control third-party public-node operators.
